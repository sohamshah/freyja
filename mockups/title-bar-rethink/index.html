chrome earned its place

Five pills left. The rule: a TitleBar element earns its slot only if it changes during normal work or locks at a moment of choice. Static "live" pills (slack, bridge, daemon) violate the rule — they're system metadata, not feedback to your action.
2 right-rail sections out

activity = activity

Skills and memory ended up in the activity panel because we had no better home. They aren't activity — they're stable inventories. The palette opens a dedicated surface for each. The activity rail returns to its job: showing what the agent did this turn.
cost

what you give up

Glanceability of background services. Slack going down is now a failed-action discovery, not a chrome tell. For services that need attention in real time (computer-use sessions, scheduler runs in flight), a single one-pixel ambient indicator next to session-id would carry the load — without re-introducing pills.
